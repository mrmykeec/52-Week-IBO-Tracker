# 52-Week IBO Tracker

A single-file HTML tracker for the WWG 52-week IBO training program designed by Jake & Jolene Carrithers.

## What's here

- **`52-week-tracker.html`** is the version shared with the team. Identical contents to the latest dev version.
- **`tracker-vN.html`** files are the version history (v1 through v12). Kept for diffing and rollback.
- **`NOTES.md`** is the decision log: why the tracker is built the way it is, what's intentional, and what's open for future versions.
- **`build_tracker.py`**, **`_test_linkify.*`** are helper and smoke-test scripts.

## How to use it

Open `52-week-tracker.html` in any modern browser. Progress is stored in the browser's localStorage on the device that opens it. There's no install, no account, and no backend.

Use the **Export Backup** button periodically. Clearing browser data wipes progress otherwise.
